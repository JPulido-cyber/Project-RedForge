# Raw evidence intake

Place candidate screenshots here for local review only.

Raw image files are intentionally excluded from Git because they may contain
personal data, secrets, unrelated desktop content, or evidence that has not
been checked for accuracy. After review, copy only an approved or minimally
sanitized result into `../Reviewed/`, assign a descriptive filename, and add it
to `../Published/manifest.json`.

Never use a raw file directly from website content.
