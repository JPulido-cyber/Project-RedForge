# Website evidence presentation

Website evidence is served from `/public/evidence` and referenced by typed
project and documentation content.

Presentation rules:

- identify each screenshot as reviewed implementation evidence;
- preserve visible hostnames, directory structure, DNS, Group Policy, indexes,
  searches, logs, and other legitimate engineering content;
- distinguish screenshots from conceptual architecture diagrams;
- provide descriptive alternative text and captions;
- link to the original-size image;
- never imply that an image validates work beyond what it visibly demonstrates.
